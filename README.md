# G.账 v0.4.0

\[English](README\_EN.md)

一款为 Android 设计的个人财务 App。默认货币为马币（MYR），支持中文和英文。



## 当前功能

* 手账纸张视觉：暖白网格纸、纸胶带、轻量手绘元素；左上角仅显示 `G.`
* 记账金额内置四则运算计算器，并可记住尚未分配的余额
* 单笔账单支持项目细分，主账单只扣款一次
* 高级 AA 结算：每人实际消费／垫付不同，税费、服务费与折扣按消费比例分配，并生成最少转账方案
* 账户页采用卡包式阶梯排列，顶部同时显示总资产、净资产、本月收入与支出
* 拍摄或选择收据后，在 Android 设备本地识别商家、日期、总额、税费和项目
* Android 快捷设置中的“G.账识别”可截图识别，并将结果加入待确认账目
* 电子资产、购买日期、金额、配置／序列号、原账单和照片
* 自动计算已使用天数、每天平均花费、回本状态和保修剩余天数
* 保修到期前预警，默认提前 30 天且可自行调整
* 最新多币种汇率、本位币折算与断网汇率缓存
* AA 参与者可分别使用不同消费币种与垫付币种
* 账单详情查看、修改，以及 AA 历史编辑／分享
* 资产保养、维修、配件、转卖、残值和完整生命周期
* Android 系统级周期账目、分期与保修提醒
* WebDAV 手动上传／下载完整备份，可作为自己的多设备或共享账簿空间
* 可配置兼容接口地址、模型和密钥的 AI 月度分析助手
* 收据商家本地规则分类，识别后自动建议支出分类
* 照片改存 IndexedDB 附件库，完整备份会同时带上附件
* 收入、支出、账户互转与转账手续费
* 现金、银行、电子钱包、储蓄、信用卡和先用后付账户
* 先用后付额度、欠款、分期期数、到期日与还款分配
* “别人欠我／我欠别人”债务追踪、部分还款和一键结清
* 账户余额调整（通过独立调整流水保留账务轨迹）
* 房租、订阅等每月周期项目及待确认流水
* 信用卡／先用后付大件分期、手续费和未来还款排期
* 拍照或上传小票、电子发票及商品截图
* 自定义二级分类和多标签
* 关联原始消费的部分／全额退款
* 多账簿
* 分类、备注、日期、关键词、时间段、账户及分类筛选
* 月度收入、支出、结余、分类分析、排行榜和消费日历
* 环比上月及同比去年同期
* 分类月度预算与超支显示
* 净资产、总资产、信用欠款与个人债务
* 一键隐藏所有敏感金额
* JSON 完整备份／恢复及 CSV 导出
* 中文／英文切换和深色模式
* Android 竖屏锁定
* 独立 AI Provider 接口，方便未来接入本机模型或用户主动选择的 API

## 数据与网络

v0.4 采用“本机优先、功能按需联网”：汇率会自动尝试更新并缓存；WebDAV 只有按下上传／下载时才传输完整备份；AI 只有启用并主动按下分析时，才会发送当月汇总。收据识别使用随 APK 打包的 ML Kit 模型，可在无网状态下运行。更换手机或卸载前，请先在 App 内导出完整 JSON 备份。

快捷截图遵循 Android 的系统隐私机制：Android 14 及更新版本每次都必须由用户确认屏幕捕获授权。识别完成后仍需在 App 的“待确认账目”中确认，避免误识别直接改变余额。

## Android 构建

要求：

* Android Studio（附带 Android SDK）
* Node.js 20 或更新版本
* JDK 17

步骤：

1. 在项目目录执行 `npm install`
2. 执行 `npm run android:sync`
3. 执行 `npm run android:open`
4. 在 Android Studio 选择 **Build > Build APK(s)**

Android 工程已经生成在 `android/`。为方便直接解压后编译，所需的
Capacitor Android 原生模块也已包含在工程中，不要求先安装 Node.js。
网页生产版本位于 `dist/`。

首次构建时，Android Studio 需要联网下载 ML Kit 与 WorkManager 编译依赖；
这些识别模型会打包进 APK，安装后的实际识别可离线运行。

## 快捷截图识别

1. 安装并打开 App 一次
2. 下拉 Android 快捷设置，点击编辑／铅笔
3. 将“G.账识别”拖入快捷设置
4. 以后在付款页面点击该快捷键，并确认系统屏幕捕获授权
5. 识别完成后打开 G.账，在“更多 > 待确认账目”确认金额

Android 14 及更新版本要求每次截图都重新确认授权，这是系统隐私限制。

## 测试

运行 `npm test`。测试覆盖先用后付消费与还款、报表不重复计算、记账计算器、AA 税费分摊与最少转账、电子资产日均成本／保修倒计时、收据文字解析、自动分类及多币种换算。

## AI 接口

“更多 > AI 财务助手”可以填写兼容 Chat Completions 的接口地址、模型名称和 API Key。功能默认关闭；主动分析时只发送界面明确列出的月度汇总，不发送收据照片。

## v0.4 测试版说明

本版本优先让所有功能形成可操作流程。云端共享目前使用用户自己的 WebDAV 文件，不包含中央账号注册、实时同时编辑或细粒度服务器权限；多人同时改同一远端文件时，应先下载再修改、最后上传。后续版本会重点处理自动冲突合并、原生设备兼容测试与界面细节。
